# StarBintang — setup GitHub Pages + Supabase baru

## 1. Buka di VS Code
1. Ekstrak ZIP ini.
2. Di VS Code pilih **File → Open Folder…** dan buka folder `StarBintang`.
3. Untuk preview lokal, buka `index.html` lewat Live Server.

## 2. Buat project Supabase BARU
1. Buka https://supabase.com/dashboard lalu buat project baru. Simpan nama project dan password database dengan aman.
2. Buka **SQL Editor → New query**, lalu jalankan SQL ini:

```sql
create table if not exists public.memories (
  id bigint generated by default as identity primary key,
  title text,
  memory_date date,
  public_url text not null,
  file_name text,
  mime_type text,
  storage_path text,
  created_at timestamptz not null default now()
);
alter table public.memories enable row level security;
create policy "Public can view memories" on public.memories for select to anon, authenticated using (true);
create policy "Public can add memories" on public.memories for insert to anon, authenticated with check (true);
```

Jika policy bernama sama sudah ada, jangan buat duplikat.

### Buat bucket
1. Buka **Storage → New bucket**.
2. Nama persis: `StarB1ntang-media`.
3. Aktifkan **Public bucket**.
4. Di **SQL Editor**, buat policy upload berikut jika belum ada:

```sql
create policy "Public can upload StarBintang media"
on storage.objects for insert to anon, authenticated
with check (bucket_id = 'StarB1ntang-media');
```

**Peringatan:** ini mengizinkan siapa pun mengunggah ke galeri publik. Untuk pemakaian ramai, tambahkan login atau batasi unggahan. Jangan pernah memakai `service_role`/secret key di frontend.

## 3. Hubungkan website ke Supabase baru
Di dashboard project baru, cari **Project URL** dan **Publishable key** (atau legacy `anon` public key). Buka `app.js` dan ganti dua konstanta teratas:

```js
const SUPABASE_URL = "https://PROJECT-ID-BARU.supabase.co";
const SUPABASE_ANON_KEY = "TEMPEL_PUBLISHABLE_KEY_DI_SINI";
const STORAGE_BUCKET = "StarB1ntang-media";
const TABLE_NAME = "memories";
```

Gunakan URL dan key dari project BARU, bukan project lama. Simpan file. Jangan kirim key lewat chat publik.

## 4. Buat repository GitHub baru
1. Buka https://github.com/new dan buat repository bernama `StarB1ntang` (atau nama baru yang kamu pilih). Untuk paling mudah, pilih **Public**.
2. Upload `index.html`, `style.css`, `app.js`, dan `SETUP.md` ke root repository.
3. Buka **Settings → Pages**. Pilih **Deploy from a branch**, branch `main`, folder `/(root)`, lalu Save.
4. Setelah selesai, alamat biasanya `https://USERNAME.github.io/NAMA-REPOSITORY/`.

GitHub Pages hanya meng-host halaman website. Supabase menyimpan file foto/video dan metadata supaya pengunjung lain melihat galeri yang sama.

## 5. Perbaikan tampilan foto
Saat thumbnail diklik, foto ditampilkan dengan `object-fit: contain` di viewer yang mengikuti ukuran layar. Foto utuh ditampilkan tanpa dipotong atau diperbesar paksa. Thumbnail galeri tetap menggunakan `cover` agar grid rapi.

## 6. Tes
1. Upload satu foto lewat website publik.
2. Pastikan foto muncul kembali setelah halaman dimuat ulang.
3. Buka URL website di browser/HP lain.

Jika gagal, buka Developer Tools → Console dan periksa error. `row-level security` biasanya berarti policy tabel/storage belum sesuai; `Bucket not found` berarti nama bucket tidak cocok.
